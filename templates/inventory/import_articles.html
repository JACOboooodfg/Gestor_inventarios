Importar Artículos desde Excel

📋 Formato del Archivo Excel

El archivo debe tener las siguientes columnas (en la primera fila):

  • nombre (requerido): Nombre del artículo
  • categoria (requerido): Nombre de la categoría (se crea si no existe)
  • cantidad (requerido): Cantidad en stock
  • codigo (opcional): Se auto-genera si está vacío
  • ubicacion (opcional): Nombre de la ubicación (debe existir)
  • unidad (opcional): Default es "unidad"
  • cantidad_minima (opcional): Default es 5
  • estado (opcional): Default es "available"
  • precio (opcional): Precio unitario
  • codigo_barras (opcional)
  • descripcion (opcional)
  • notas (opcional)
